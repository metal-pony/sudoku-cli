# Sudoku-cli

Commandline interface for generating, solving sudokus.

## Build Requirements

Java JDK >= 21 for various syntax features.

GraalVM 21+ is required if building a native executable, which in turn has its own prerequisites of C compilation tools. See https://www.graalvm.org/latest/reference-manual/native-image/#prerequisites.

## Building a JAR

> ./mvnw clean package

The JAR file will be built as `target/sudoku-cli-1.jar`.

## Building a native executable

Have GraalVM 21+ installed as your Java version. Then,
> ./mvnw clean package -Pnative

The executable will be built as `target/sudoku`.

### Solve

```
Usage: sudoku solve [-v] [--all] [--json] [--amount=<arg2>] [GRID]
Solves the given sudoku grid.
      [GRID]            Sudoku grid to solve.
      --all             Include all solutions (overrides amount if set).
      --amount=<arg2>   Include up to {amount} solutions.
      --json
  -v, --v, --verbose    Show detailed output.
```

By default, `solve` gets one solution. If there are multiple solutions to the supplied grid, use the `--all` option to get them all, or `--amount={N}` to get up to the specified amount.

## Palindrome Search

⚠️ EXPERIMENTAL

A comprehensive search of ALL palindrome puzzles for a solution with a certain number of clues.

By default, uses a random solution and 24 clues.

⚠️ Too few clues (<= 21) will generate little-to-no data; while too many will generate gigabytes worth of puzzles (and will take a long time).

Multi-threading on this command is not currently supported.

```
Usage: sudoku paliSearch [-v] [--pretty] [--clues=N] [SOLUTION]
Generates all palindrome sudoku puzzles with N clues for a solution.
      [SOLUTION]       Solution to generate puzzles for.
      --clues=N        Number of clues on generated puzzles.
      --pretty         Format output to use multiple lines.
  -v, --v, --verbose   Show detailed output.
```
